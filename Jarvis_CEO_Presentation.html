03. SYSTEM ARCHITECTURE

Enterprise-Grade Architecture

Unlike cloud AI, Jarvis runs entirely on-premise. We designed it with the same security principles used by top Silicon Valley firms.

🧠 The Brain (Local AI)

  • Manager LLM: Qwen 2.5 (7B)
  • Worker LLM: Llama 3.2 (3B)
  • Vector DB: ChromaDB (for RAG)
  • No internet required for inference.

🛡️ Security (Zero-Trust)

  • Dockerized Microservices
  • Squid Proxy (Strict API Allowlist)
  • Fernet Encryption for all memory
  • Human-in-the-loop (No auto-send)
Data Privacy: Your data, meeting notes, and email drafts never leave your laptop. There are no OpenAI or Google Cloud API calls. This is 100% PDPL compliant.

06. THE FUTURE: VOICE CONTROL

Next Phase: Iron Man-Style Voice Control

As requested, we are moving from a text dashboard to a fully voice-driven assistant.

🎙️ Push-to-Talk (Phase 1)

Press a hotkey, speak your command ("Summarize my emails"), and Jarvis will speak the answer back using secure, local TTS (Piper).

👏 Double-Clap Wake-Up (Phase 2)

Clap twice, and Jarvis wakes up on your screen, opens your tools, and gives you the morning briefing.

Voice Approval System

For security, Jarvis will never send an email on voice command alone. It will say: "Boss, I drafted this to X. Say 'Confirm approval: Four, Eight, Two, One'." This prevents accidental voice triggers.

08. STRATEGIC ALIGNMENT

Decisions Required from CEO

To align Jarvis with your risk appetite and business strategy, we need your sign-off on the following:

1. LinkedIn Automation Risk

Automating LinkedIn outreach (even pre-filling drafts) violates LinkedIn's ToS and risks an account ban. Do you authorize us to proceed with the Playwright browser automation, or should Jarvis only generate drafts for you to copy-paste manually?

2. Etimad Live API Access

Our current scraper works perfectly on offline HTML. To fetch live data, Etimad uses bot protection (CAPTCHA). We need you to authorize obtaining official API credentials from Etimad (apiportal.etimad.sa) to ensure uninterrupted access.

3. Cloud vs. Local Voice

We have a local voice model (Piper) which is 100% secure but sounds slightly robotic. Do you prefer local security, or should we use ElevenLabs (Cloud) for a more natural voice, at the cost of data leaving our local machine?
